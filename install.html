Trainer App – 1 minute mein install karo

⚠️ Pehle browser mein kholo

Ye link WhatsApp/Instagram ke andar khula hai – yahan se install nahi hoga.

Upar right corner mein ⋮ ya ⋯ dabao → "Open in Chrome" (Android) ya "Open in Safari" (iPhone).

✅ App already install hai

App kholo

🤖 Android Phone

  1. Ye page Google Chrome mein khula hona chahiye
  2. Upar right mein ⋮ (3 dots) dabao
  3. "Install app" ya "Add to Home screen" dabao → Install
  4. Home screen pe Iron Bunker icon aa jayega – wahi se kholna

🍎 iPhone

  1. Ye page Safari mein khula hona chahiye
  2. Neeche Share button ⬆️ dabao
  3. Scroll karke "Add to Home Screen" dabao
  4. Upar right "Add" dabao
  5. Home screen pe Iron Bunker icon aa jayega – wahi se kholna

📌 Zaroori

  1. App hamesha home screen icon se kholo, browser se nahi
  2. Pehli baar kholne pe apna naam daal ke setup karo
  3. Aapka data aapke phone mein save hota hai – app delete mat karna
